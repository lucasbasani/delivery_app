# PedeAi

Aplicativo mobile de restaurante desenvolvido em Flutter.

## Objetivo

O PedeAi tem como objetivo permitir que clientes visualizem produtos de um restaurante, pesquisem itens, filtrem produtos por categoria, adicionem produtos à sacola e finalizem pedidos.

## Tecnologias

- Flutter
- Dart
- Provider
- Material Design

## Funcionalidades da Parte 1

- Tela de login
- Cadastro de usuário
- Validação dos formulários
- Feedback através de mensagens
- Tela inicial do restaurante
- Pesquisa de produtos
- Filtro por categorias
- Visualização dos produtos
- Adição de produtos à sacola
- Alteração da quantidade dos produtos
- Remoção de produtos
- Cálculo do valor total
- Finalização de pedido simulada
- Logout
- Gerenciamento de estado utilizando Provider

## Arquitetura

O projeto foi organizado utilizando uma estrutura baseada em separação de responsabilidades:

- models: modelos de dados
- providers: gerenciamento de estado
- services: regras relacionadas aos serviços
- views: telas da aplicação
- widgets: componentes reutilizáveis
